# Price prediction

Решение в: notebook_solution.ipynb

## Поставленная задача
Участникам предоставлен набор данных объявлений о продаже недвижимости в некотором городе N. Задача - предсказать цену недвижимости по содержанию объявления.

## Описание решения
Импортировал данные и настроил random seed для воспроизводимости случайных операций.

Для предобработки данных использовал отдельную функцию:
- date разделил на два целочисленных признака: year и month
- пропущенные значения metro_dist заполнил средним значением по street_id
- пропущенные значения build_tech и g_lift заполнил случайными значениями из известных значений соответствующих признаков.

Для предсказания использовал CatBoostRegressor, т.к. он позволяет работать с категориальными признаками без необходимости кодировать их вручную. В качестве категориальных признаков использовал street_id и build_tech.

В качестве функции потерь использовал MAE, т.к. именно эта метрика использовалась для оценки решения в задании.

Гиперпараметры CatBoostRegressor подбирал перебором.

После обучения получил предсказания для тестовой выборки и сохранил результат в submission.csv.
